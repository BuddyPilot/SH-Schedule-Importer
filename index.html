    Turn the monthly schedule workbook into calendar events. No retyping.

    1 · Schedule file

    TAP TO CHOOSE · OR DROP .XLSX
    Reads the WaffleSheet tab. Nothing leaves this device.

    2 · Your line

    Events run 6 hours from the report time; SF runs 5:30, and a standardization meeting is 0900–1600 with STAN or 0800–1600 with SC, and ODAWG is 0800–1700. Timed events alert 45 and 30 minutes before; all-day events such as WDAY alert at 1630 the day before. Title comes from the event row, location from the room number.

    3 · Check it against the sheet

    4 · Send to Google Calendar

    One-time setup in Google Cloud Console: enable the Calendar API, create an OAuth client ID of type Web application, and list this page's address under authorized JavaScript origins. Paste the ID here, or set GOOGLE_CLIENT_ID near the top of this file's script so it fills itself in.

    5 · Or take the file

    1. On a computer, open calendar.google.com → gear icon → Settings → Import & export.
    2. Pick the downloaded file, choose which calendar receives it, then Import.
    3. Either route uses the same fixed event ID built from your employee number and the date, so next month's run updates existing entries instead of doubling them.
